# KGD-419 / KGD-442 / KGD-444 / KGD-445

## Status

Implemented as metadata-only validation and reachability contracts.

## Delivered

- `import::content::reachable_content` computes a strict graph closure from
  logical roots, reports unreachable nodes, and reports dangling references.
- `ReachabilityReport` has a versioned schema and validates deterministic,
  sorted identifiers.
- `import::content::validate_locales` checks duplicate string identifiers,
  missing fallback locales, and fallback cycles without reading string bytes.
- Helpers project imported asset IDs and story descriptor IDs into graph nodes.
- Synthetic tests cover closure, orphan detection, dangling references, and
  valid/missing locale fallback chains.

No proprietary DDLC text, images, audio, or other recovered bytes were added.
The implementation consumes player-owned import metadata and remains suitable
for future AssetRipper adapters once their references are parsed and proven.
