# KGD-001 report

Implemented `scripts/check-kg-scope.py`, a dependency-free checker for the
`kg_ddlc_plus` execution ledger.

It validates packet IDs and duplicate definitions, expands compact dependency
ranges, rejects missing dependencies and descending/invalid ranges, checks the
declared status vocabulary, validates referenced task reports, and detects
dependency cycles. `--json` emits the machine-readable packet/dependency graph
for later governance tooling.

Changed paths:

- `scripts/check-kg-scope.py`
- `docs/task_reports/KGD-001.md`

Tests:

- `python3 scripts/check-kg-scope.py` (correctly reports pre-existing ledger
  references to undeclared packets KGD-319, KGD-426–429, and KGD-436–439)
- `python3 scripts/check-kg-scope.py --json`

Source counts: no proprietary source, recovered assets, absolute paths, or
private fixtures added.

Limitations: the checker validates ledger structure and explicitly referenced
reports; it does not interpret deliverable prose or acceptance commands.

Follow-up risk: the ledger must declare or remove the nine missing dependency
IDs before the governance gate can pass. Future ledger syntax changes must also
update the compact dependency parser and its synthetic malformed-ledger tests.
