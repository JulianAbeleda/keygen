# Story session runtime qualification

Implemented the content-agnostic session adapter for the imported `keygen.story.v1`
program format.

- `StorySession` starts at an imported label and advances the deterministic VM to a
  dialogue, choice, or completion boundary.
- `menu_input` capability payloads expose prompt/entries/label targets; selecting an
  entry updates the VM cursor and persists the choice in `SessionState`.
- VM `Set` effects and capability-emitted `Set` effects project into bounded session
  variables; dialogue lines enter the bounded history.
- Replay proofs remain derived from the VM trace, with no content or platform data
  embedded in the adapter.
- Persistence uses the existing checksummed `AtomicStore` through `SessionState`.

Validation: `cargo test -p kg-ddlc-plus` (30 tests passed).
