# KGD-122–131 bounded import-contract pass

This pass adds metadata-only Rust contracts under
`crates/kg_ddlc_plus/src/import/`. It does not read, copy, decode, or commit
any recovered game asset or source code. The contracts are intentionally
synthetic and are suitable for importer and schema tests before a local
recovery adapter is implemented.

| Task | Contract module | Preserved metadata | Explicitly not implemented |
| --- | --- | --- | --- |
| KGD-122 | `sprites` | rect, pivot, border, pixels-per-unit, mesh, stable order | atlas decoding/packing and mesh rasterization |
| KGD-123 | `fonts` | face, glyph/line metrics, kerning, fallback, sprite-font mappings, byte hash | font parsing, shaping, and glyph extraction |
| KGD-124 | `audio` | codec, decoded PCM hash, channels, rate, duration, loop region | codec decoding, resampling, playback |
| KGD-125 | `animation` | bindings, keyframe counts, tangents, wrap, events | Unity curve decoding and controller evaluation |
| KGD-126 | `scene` | stable object IDs, parentage, components, references, sibling order | serialized scene/prefab parsing |
| KGD-127 | `ui` | canvas mode, reference resolution, rect transform, masks, navigation, sorting | layout evaluation and clipping |
| KGD-128 | `materials` | shader identity, typed properties, texture bindings, support flag | shader execution and unknown shader translation |
| KGD-129 | `locales` | locale strings, sprite/font IDs, bundle variants, fallback | localization table/bundle extraction |
| KGD-130 | `story` | typed story identity, characters/styles/audio tables, blocks, labels, variants | descriptor decoding and semantic command execution |
| KGD-131 | `dependencies` | label-to-bundle edges and deterministic transitive closure | bundle graph extraction and cycle policy |

All unsupported source features must be reported with diagnostics code
`KGD-002` (`keygen-diagnostics::CODE_UNSUPPORTED`) and source `import`; they
must not silently degrade to guessed values. The synthetic tests verify JSON
round trips, stable diagnostics, and deterministic dependency closure without
embedding private paths or asset bytes.

## Deliberate limitations

This is a contract pass, not a functional DDLC importer. The current compiler
continues to use its existing BIOS-only path. A later recovery adapter may
populate these records from a player-owned export, but must preserve the
metadata fields and attach provenance/source hashes outside the public source
tree. The contracts do not claim that the 34 story descriptor variants, 82
bundles, or any recovered object has been imported yet.
