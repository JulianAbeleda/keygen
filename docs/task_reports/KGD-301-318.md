# KGD-301–318: retained scene runtime

Implemented in `crates/engine/src/scene/` as a product-neutral, deterministic
scene-v2 contract. The module has no filesystem, window, audio, or asset
loading dependencies; hosts provide resource bytes and importers provide
versioned values.

Coverage:

- `SceneDocument`/strict serde schema, node kinds, camera/reference data,
  sprites, text, masks, nine-slice, materials, animations, and widgets.
- Retained create/update/remove/reparent/order operations with stable z/id
  traversal and snapshot equality.
- Transform matrices, viewport mapping, clipping intersection, and nine-slice
  source/destination regions.
- Deterministic glyph placement contract with wrapping and alignment.
- Fixed microsecond animation clock, tracks, easing, repeat, and sampled trace.
- Typed material properties plus explicit fallback policy; unknown effects are
  represented rather than silently substituted.
- Resource ownership groups with deterministic release lists.
- Transition progress, screen activation/modal stack, semantic focus graph,
  and widget state/focusability primitives.

The existing v1 compositor remains unchanged. KGD-318 migration is deliberately
a scaffold: v1 importers can construct `SceneDocument` values, while the v1
`SceneSpec` remains the compatibility input until the compositor migration is
completed. No DDLC mappings or proprietary assets are included in this change.

Verification: `cargo fmt --all` and
`cargo test -p keygen-engine scene::tests` (4 synthetic tests passing).
