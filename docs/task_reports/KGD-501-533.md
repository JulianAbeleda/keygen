# KGD-501–533 macOS packaging

Implemented the macOS-only distribution boundary for `kg_ddlc_plus`.

`scripts/package-macos-app.sh` assembles `dist/macos/kg_ddlc_plus.app` from an
already-built arm64 executable and an optional imported package directory. It
rejects non-macOS hosts, non-arm64 hosts, and non-arm64 binaries, and writes the
fixed identity `com.julian.keygen.kg-ddlc-plus` with a deployment floor of 15.0.
A content-addressed package manifest records every bundled file. Existing
output is replaced only at the exact app path; source assets and other bundles
are not searched for or modified.

`scripts/smoke-macos-app.sh` verifies the bundle layout, executable architecture,
Info.plist identity, deployment floor, and every manifest hash. Both scripts
reuse the compiled player and imported package; they do not include proprietary
source data or generate assets.

Run on Apple Silicon macOS:

```sh
cargo build -p kg-ddlc-plus --release
scripts/package-macos-app.sh --binary target/release/kg-ddlc-plus
scripts/smoke-macos-app.sh
```

Native runtime/UI and code-signing/notarization remain separate adapters; this
packet establishes the deterministic app boundary and its qualification gate.
