# KGD-400–411 — story VM foundation

Implemented in `crates/engine/src/story.rs` as a platform-neutral, product-independent
module. The `keygen.story.v1` schema is strict at the program boundary and exposes
typed values, blocks, labels, cursor/call stack, local/global/persistent scopes, waits,
effects, capability registration, snapshots, cancellation, and deterministic traces.

The schema enumerates all 34 descriptor tags required by the compatibility ledger:
dialogue/UI, image, transform/timing, audio, flow/scheduling, mutation, and call
families. Execution emits typed effects only; no descriptor can perform host I/O or
invoke arbitrary reflection. Unknown schemas, labels, argument types, negative waits,
and missing required arguments fail with diagnostics.

Synthetic tests cover serialization of every tag, typed mutation, snapshot round-trip,
and deterministic stepping. No DDLC text, asset, path, or proprietary fixture is part
of this change. Product-specific descriptor decoding and capability implementations
remain in the importer/product layers as intended.

Validation: `cargo fmt --all`; `cargo test -p keygen-engine`.
