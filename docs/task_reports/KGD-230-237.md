# KGD-230–237 launcher application contracts

Status: implementation slice complete; launcher-root integration is intentionally deferred to the integration packet.

The isolated module at `crates/kg_ddlc_plus/src/launcher/apps/mod.rs` defines deterministic, serializable state reducers for:

| Packet | Contract |
| --- | --- |
| KGD-230 | Virtual-file browser hierarchy, selection, open, delete gate, and reset-safe confirmation |
| KGD-231 | File viewer text/sprite/audio mode selection and return handoff |
| KGD-232 | Mail projection, last-viewed state, and unlock notification |
| KGD-233 | Side-story unlock projection, confirmation, launch parameter, and return effect |
| KGD-234 | Gallery unlock/category projection and image selection |
| KGD-235 | Jukebox selection, play/pause/queue, and audio intents |
| KGD-236 | Settings preference updates, dirty state, and close persistence boundary |
| KGD-237 | Seeded VM output, gated reset, reset effect, and audio stop |

All inputs are typed (`VirtualFileSystem`, `UnlockState`, `AudioTrack`, `AppAction`) and all external work is represented as `AppEffect`. No reducer reads host paths, invokes audio, mutates an unlock store, or embeds recovered game content. The integration layer must supply those adapters and route effects through the existing engine audio/state contracts.

Synthetic tests cover virtual file navigation/viewing, unlock filtering, jukebox audio intents, and VM reset gating/determinism. The module is not exported from the crate root yet so the launcher-core integration packet can establish the final public wiring and avoid a partial API.
