# KGD-412–425, KGD-444–445: story capability and replay boundary

Implemented `crates/kg_ddlc_plus/src/story/mod.rs` as the host-facing closure for
the deterministic `keygen_engine::story` VM:

| Packet | Contract |
|---|---|
| KGD-412–413 | typed capability requests/responses, bounded registry, missing/failed diagnostics |
| KGD-414–420 | stable snake-case capability IDs, engine-effect conversion, cancellation boundary |
| KGD-421–425 | replay proof schema and SHA-256 trace identity for deterministic host validation |
| KGD-444–445 | replay divergence and invalid-proof diagnostics with stable fields |

Handlers receive only typed story data and a cancellation token. The registry has no
filesystem, process, network, or platform access; hosts must explicitly register each
capability. Cancellation is checked before dispatch and produces no effects. Replay
proofs hash serialized engine trace events and validation reports the first differing
event or a length mismatch.

Tests cover registration/dispatch, canonical IDs, missing and failed handlers,
cancellation, proof generation, and deterministic divergence detection. No proprietary
DDLC content or recovered asset bytes are included.

Validation: `cargo fmt --all`, `cargo clippy -p kg-ddlc-plus --all-targets -- -D warnings`,
`cargo test -p kg-ddlc-plus` (27 tests passed).
