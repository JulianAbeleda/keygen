# KGD-330–332, 430, 435, 440, 441, 500

Implemented reusable deterministic contracts for audio channels, normalized
input, and player-side persistence. Audio state keeps ownership, queue, fade,
position, generation-based cancellation, snapshot, and handoff explicit.
Input adapters can translate native keyboard, pointer, text, focus, and device
events into replayable events; focus and input locks gate normalized actions.
Player storage uses a versioned JSON envelope, SHA-256 payload checksums,
temporary-file write plus sync and rename, schema checks, and a sandboxed
logical-path API. Preferences and local unlock events are validated and
idempotent without a Steam dependency.

Changed paths:

- `crates/engine/src/audio.rs`
- `crates/engine/src/input.rs`
- `crates/engine/src/lib.rs`
- `crates/player/src/storage.rs`
- `crates/player/src/lib.rs`
- `crates/player/Cargo.toml`

Tests cover channel ownership, queue completion, fade/snapshot determinism,
stale cancellation, focus/lock action gating, atomic metadata/checksum
validation, traversal rejection, preferences validation, and unlock/reset
behavior. Tests use synthetic temporary directories only; no recovered or
proprietary content is tracked.

The modules are intentionally independent of product and renderer code. Later
macOS CoreAudio and native event adapters can consume these public contracts.
