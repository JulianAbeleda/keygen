# KGD-320–329: Native VN screen contracts

Implemented content-agnostic reducers under `crates/kg_ddlc_plus/src/vn/`:

| Packet | Contract |
|---|---|
| KGD-320 | dialogue screen and speaker/text model |
| KGD-321 | Unicode-safe typewriter reveal and confirm-to-complete |
| KGD-322 | wrapped choice selection and confirm result |
| KGD-323 | main menu selection |
| KGD-324 | bounded history and scrolling |
| KGD-325 | save/load slot commands |
| KGD-326 | validated preferences handoff |
| KGD-327 | bounded Unicode name entry |
| KGD-328 | poetry selection/submission |
| KGD-329 | special-screen acknowledgement and shared runtime context |

The shared context consumes KeyGen input events and emits story/audio effects through
the existing engine contracts. Persistence uses the existing `keygen-player::storage`
types. No proprietary scripts, assets, or source paths are included. Each contract is
content-agnostic and can be populated by the importer at runtime.

Validation: `cargo fmt --all`, `cargo test -p kg-ddlc-plus`.
