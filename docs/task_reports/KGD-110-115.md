# KGD-110–115 report

Status: implemented as a read-only diagnostic foundation.

## Delivered

- `kg_ddlc_plus::source::discover_steam_app` discovers the conventional
  macOS Steam install without recording the operator's path.
- `exported_project` verifies the pinned Unity version and required recovery
  files, then emits deterministic logical paths, byte counts, kinds, and SHA256
  digests.
- `inventory` aggregates deterministic per-kind counts over the recovered
  export.
- `reference_graph` provides stable logical nodes. Edges remain empty until a
  serialized-object parser proves a relationship; the adapter never fabricates
  edges.
- `classify` assigns every inventory object a known state. Unknown extensions
  become `blocked`; recognized classes become `imported`.

## Privacy and provenance

The module contains no recovered assets, absolute source paths, source text,
or private fixtures. Results contain only logical paths and content hashes.
The local AssetRipper export is read-only input and is not required to run the
unit tests.

## Verification

```text
cargo test -p kg-ddlc-plus
7 passed
```

The adapter intentionally does not claim full Unity serialized-reference
coverage. KGD-114's parser-specific edges and KGD-115's reachability roots are
follow-up work once the relevant serialized formats are imported.
