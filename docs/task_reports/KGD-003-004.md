# KGD-003 / KGD-004 report

## KGD-003 — structured diagnostics

Added the `keygen-diagnostics` crate at `crates/diagnostics/`. It provides a
stable `Diagnostic` record with string code, severity, logical source ID,
message, and deterministic ordered fields. The catalog includes the initial
codes used by importer/package/runtime boundaries. JSON uses a versionless
record format deliberately suitable for logs; unknown fields fail closed.

`Diagnostic::redacted_json` removes fields whose keys identify local paths,
home directories, tokens, or secrets before serialization. No machine paths,
assets, or recovery fixtures are included.

## KGD-004 — evidence manifest

Added `kg_ddlc_plus::evidence` with the versioned `keygen.evidence.v1`
manifest schema. It records target, portable source-build identity, and
structured observations for asset reuse, behavior, render, and schema
evidence. Validation rejects unknown schema versions, missing identity, and
non-portable fact keys. It contains no source paths or proprietary data.

Result: 7 tests passed. The workspace manifest now includes the diagnostics
